WHEN SOMETHING INTERRUPTS THE DESK

Keep custody clear.

Stop, check the record, then check the physical packet.

01 / CONNECTION

The app stops responding

Do not hand out a pass based on an old screen. The local server must confirm a release first. Reopen the app, search the packet, and inspect its status before retrying.

02 / UNCERTAIN HANDOVER

“Release recorded” is not a second release

Check whether the original packet is still physically at the desk. The original operator can confirm a handover already made, or hand over that same packet once if still held. If unsure, stop and involve the supervisor.

03 / FULL OUTAGE

One paper ledger, one release point

A supervisor must stop all digital release stations before switching to paper. Record unique packet IDs, collector, operator, quantity and time. Reconcile every paper action before digital releases resume. Paper reconciliation is not implemented in this prototype.

04 / RESTORE

A backup is not current custody

Never restore an earlier database and immediately resume releases. Later handovers may be missing. Stop operations, compare all paper and physical records, and reconcile first. There is no automatic restore or failover.

Prototype boundaries

One trusted laptop operator. Staff names are audit labels, not authenticated identities. No multi-device operation, admission validation, digital-ticket transfer, ID exceptions, reassignment, or real customer data. No remote assets or internet-dependent services.
