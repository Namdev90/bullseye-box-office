DESK PROCEDURE

At the desk

01

Receive & store

Count Normal, VIP and VVIP passes. Store one packet in a fresh shelf slot. Write its packet ID on the envelope; keep the shared code private.

02

Verify & release

Verify the code for each new pickup. Match the physical packet ID. Select the exact categories, record the release, then confirm handover. The same code can collect the balance later.

03

Share privately

Anyone with the shared code can collect all remaining passes. There are no individual allocations or named collectors. Show or read the code quietly; WhatsApp sharing is optional and manual. No printed receipt.

04

If a handover is unclear

A recorded release has already reduced the balance. Reopen that packet to review the reserved quantities and physical stock. Confirm the existing handover once; never create a replacement release. If unsure, stop for supervisor review.
